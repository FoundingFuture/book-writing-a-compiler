# The split of the language out of the book

The six steps of `docs/work-order-split.md`. All six are done. The language is
`anti-lang/antic`, the book stays `FoundingFuture/book-writing-a-compiler`, and
nothing was implemented.

## What moved

`src/`, `rt/`, `std/`, `tests/`, `tools/`, `libs/`, `CMakeLists.txt`,
`.gitignore`, `.editorconfig`, `.gitattributes`, `LICENSES/` and
`.github/workflows/test.yml`. From `docs/`: `decisions.md`,
`anti-object-model.md`, `anti-language-additions.md`, `tooling.md`,
`tooling-addendum.md`, `distribution.md`, `libraries-for-c.md`, `vm-setup.md`,
`work-order-completion.md`, and the directories `notes/`, `site/` and
`reports/`. 536 files in the copy commit.

`CMakePresets.json`, `.clang-format` and `examples/` do not exist in the book
repository, so nothing was copied for them. `CMakePresets.json` is new here and
carries the two sanitizer configurations by name.

## What stayed behind

`writing-a-compiler/`, `docs/table-of-contents.md`, `docs/chapter-workflow.md`,
`docs/site-build.md`, `docs/work-order-object-model.md`,
`docs/work-order-split.md`, `tools/scripts/chapters.py`,
`tools/scripts/excerpts.py`, `tests/chapters.txt`, `tests/excerpts.txt`,
`tests/run_excerpt.cmake`, `tests/run_excerpts_complete.cmake`, the
`direct-path/` code of chapters 3 to 5 and the first `rt/start.c` of chapter 1.
The book's `README.md` stayed, and this repository has one of its own.

## Files that serve both

- `tests/CMakeLists.txt`. Copied, then four blocks removed: the chapter map that
  labels and disables tests, the excerpt tests, the direct-path programs with
  the first `start.c`, and `excerpts_complete`.
- `docs/notes/chapter-NN.md`. Named for the chapters that made them, and they
  hold the choices inside a compiler pass. They came along under their names.
- `docs/reports/`. Every earlier report mentions chapters, because the work it
  reports was done in the book repository.
- `LICENSE`. The one GitHub created for `anti-lang` stayed, MIT like the book's,
  and the book's copyright line was not copied over it.
- `tools/docs-style/check_docs.py` and `banned-terms.md`. Taken from the synced
  skill `3333c08a-cdbb-4fb4-86f8-89b534e18a7b_cae8b2d2-b39d-4574-ba34-6c17f2cb2a1e`
  on 2026-09-18. The skill carries no version number, so the directory name is
  the record. The copy is pinned on purpose.

## Test counts

The book repository: 836 tests, all passing. This repository: 404, all passing.
The 432 that stayed behind are 412 `excerpt_*`, 6 `listing_NN_M` from the
excerpt index, 12 `direct_path_*`, `excerpts_complete` and `start_01_return42`.
The error and dump listing tests are not book tests and came along.

The ASan and the UBSan builds run 403 each. They leave out `no_paths`, which
needs a build that no sanitizer wrote paths into.

## Five fixes the copy needed

- `llvm-mc` is found in the build tree beside `llvm-ar`, so a fresh clone needs
  no path on the command line.
- The `sprintf` that names an exported class is `snprintf`. A Debug build of
  clang refuses the first.
- A unit test zeroes its field records. UndefinedBehaviorSanitizer caught a
  `bool` read as 64, because the test set two members of a stack array and
  `type_pointer_free` read a third.
- `no_paths` runs on a build without a sanitizer. A sanitizer writes the path of
  the module into metadata that `-ffile-prefix-map` does not reach.
- `ANTIC_RAYLIB_DIR` is named before the first test that reads it. A cold
  configure registered 403 tests and a warm one 404, because the cache supplied
  the variable the second time.

## Not done

- The book keeps the `sprintf` and the uninitialised field record of the two
  fixes above. Its own suite passes with both, and the work order says the copies
  there are frozen. A later session in the book repository may take them.
- The LLVM tools, the sysroots and the raylib source were copied into this
  repository's build tree from the book's, rather than downloaded again. Both
  trees were installed by the pinned installers and are verified by digest. A
  machine without them runs `tools/get-llvm.cmake`, `tools/get-sysroot.cmake`
  and `tools/get-raylib.cmake`, which `README.md` states.
- Technical entries of `docs/decisions.md` keep their chapter citations where a
  chapter is the provenance of a decision. Only entries about the book alone
  were removed.
