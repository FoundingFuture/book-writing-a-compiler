# Finishing the book, session of 2026-09-18

## What is done

Step 1 is complete. Twelve commits went to `origin/main` and the web team can
publish staging. Every commit since is pushed as it landed.

Step 2 is partly done. The three fixes to the "Object model" section of
`docs/decisions.md` are applied: an abstract struct is never a complete value,
the example declares `PI`, and a `concrete fn` promotes through `use` as a
direct call. The compiler now carries the model as far as this list says.

The front end is complete for everything that does not need a table.

- `self`, `abstract`, `concrete`, `enum`, `use` and `inherits` are keywords. The
  token table reaches a library file, so `ANTL_VERSION` is 13.
- The parser reads a struct body: fields first with defaults and forms, then
  functions and constants. It reads an enum with its underlying type and its
  values, and `self` as the first parameter of a function.
- The type table holds the members of a body and the form and default of a
  field. It holds the underlying type of an enum and the number of each value.
- A function of a body is a function of the module named `module.T.f`. Its
  body sees `self` as a parameter of type `*T`.
- `Kind.Square`, `Counter.STEP` and `Counter.make(5)` reach the namespace of a
  type. `Counter.bump(&c, 2)` is the method call with the receiver written out.
- `v.f(args)` resolves in the body of the type first and then in the module. A
  function without `pub` is visible only to the functions of the same struct.
- A literal may leave out a field that has a default. Lowering writes the
  default in its place, and a constant reached through a value is refused.
- `use` and `inherits` promote fields and public functions. The checker
  rewrites `v.x` into `v.name.x` and `v.f(args)` into `T.f(&v.name, args)`. A
  promoted function is therefore a direct call through no table.
- Contracts are checked along the chain. It refuses a struct that leaves one
  unfilled, a plain function that matches an abstract one, and a concrete
  function that fills nothing.
- An enum converts with `as` to and from its underlying type.
- A pointer converts to a pointer to any type of its `inherits` chain.

The program test `object_model` runs all of that on macOS ARM64 and x86_64. 743
tests pass on the development Mac.

- Three messages the decision named without wording. They cover a constant

## What is not done, and why

The two-word pointer is not built. Everything above needs no table, and the
work stopped where one is needed. A pointer to a struct with an abstract
function changes the representation of a pointer. It therefore reaches the
layout of the target, the classification of chapter 11, both back ends, the
lowering of a call and the generated C header. That is the largest single piece
of the section, and it is where the next session starts. Until it exists:

- `[]*Shape` and dispatch through `s.area()` do not compile.
- The example of the decision is not pinned as a chapter 2 listing, because its
  last third needs dispatch.
- An abstract struct is not yet refused as a complete value, and a name that a
  struct redeclares from its chain is not yet refused.

Also not done, and untouched rather than failed:

- The library format carries no struct body, so a struct with functions does not
  cross a module boundary yet. `ANTL_VERSION` rose for the token table alone.
- The C header writes no member function and no enum.
- The eleven chapters the section names are unchanged, except where a listing
  they quote was recut to match the code. Chapter 2 still states that the
  language has no object model.
- Most of the test list of the section.
- Steps 3 to 7 in full. They are the test-mention rollout over 20 chapters and
  the two Linux link modes with PCRE2, Mbed TLS, miniaudio and raylib. They are
  also chapter 26, the chapter 23 size table, the chapter 3 terminal output and
  the two example URLs.
